# stats

Machine-written branch. `traffic.json` feeds the visitors badge on the README (shields.io endpoint schema; the number is GitHub's unique visitors over its rolling 14-day window). `history.jsonl` keeps one snapshot per day, including the per-day series GitHub discards after 14 days. Source: the repository traffic API, read once a day. Clones are recorded here but not shown as a badge, because most clones are automated fetches.
